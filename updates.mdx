---
title: "Versions and updates"
description: "Understand the version and last update shown in the loader."
---

The loader and the products inside it have separate versions.

## Product version

The version on a product card comes from the product's published **Menu updates**. For example, a menu version of `2.4` appears as **v2.4**.

If no menu version has been published, the card shows **Not specified**. Uploading another DLL does not automatically create a new menu version.

## Last update

**Last update** shows the date of the latest DLL upload. The version and date describe different things: one names the menu release, and the other tells you when the DLL was uploaded.

## Loader updates

The loader version appears at the bottom of the window. Choose **Check for updates** to check for a newer loader.

If an update is available, choose **Update Now**. The loader downloads and verifies the update, then reopens automatically after installation.

If an update fails, read the update message and choose **Retry** when you're ready.

## An update is required

**A loader update is required** means the server does not currently approve the build you're using. Use the loader's update check or obtain the current loader from your seller.
