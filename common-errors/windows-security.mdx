---
title: "Windows security warnings"
description: "Find the relevant Windows screen and understand security compatibility messages."
---

Open **Start**, type **Windows Security**, and open the app. The locations below help you inspect the setting named in your message.

<Note>
Some loader messages suggest disabling a protection. This guide does not recommend doing that: keep protections enabled and request a compatible, properly signed build from your seller. Screenshots below are Microsoft's reference images; your Windows version may look different.
</Note>

## App & browser control

**Location:** Windows Security → **App & browser control**.

<Frame caption="Microsoft reference screenshot: App & browser control.">
  <img src="https://support.microsoft.com/en-us/windows/media/app-and-browser-control-1.png" alt="Windows Security App and browser control screen showing Smart App Control, reputation-based protection and exploit protection sections." />
</Frame>

<AccordionGroup>
  <Accordion title="Exploit Protection is enabled">
    **Meaning:** The loader reports that a Windows exploit mitigation is enabled.

    **Where to look:** **App & browser control → Exploit protection settings**.

    **What to do:** Keep the existing protections. Send your seller the message and loader version so they can investigate compatibility. An enabled mitigation alone does not mean Windows is broken.
  </Accordion>
  <Accordion title="SmartScreen is enabled">
    **Meaning:** The loader reports that Windows reputation checking is enabled.

    **Where to look:** **App & browser control → Reputation-based protection settings**.

    **What to do:** If Windows blocks a file, note the warning and publisher. Ask your seller to verify the approved download and investigate the block before running it.
  </Accordion>
  <Accordion title="Smart App Control is enforcing protection">
    **Meaning:** Windows is checking whether applications are trusted. This feature is specific to Windows 11.

    **Where to look:** **App & browser control → Smart App Control settings**, if available.

    **What to do:** Install Windows updates and request a compatible, signed build if the block remains.
  </Accordion>
  <Accordion title="Reputation-based protection is enabled">
    **Meaning:** The loader reports that a reputation protection setting is active. This overlaps with SmartScreen.

    **Where to look:** **App & browser control → Reputation-based protection settings**.

    **What to do:** Record the actual Windows warning, if one appears, and contact your seller. Do not treat this message alone as proof that the file was blocked.
  </Accordion>
</AccordionGroup>

[Microsoft's guide to App & browser control](https://support.microsoft.com/en-us/windows/security/windows-security/app-browser-control-in-the-windows-security-app) explains these features.

## Antivirus protection

**Message starts with:** `An antivirus provider reports that protection is active.`

**Meaning:** A security provider reports that antivirus protection is running. This does not identify a specific detection or prove that the loader was blocked.

1. Open **Windows Security → Virus & threat protection**.
2. Check whether Windows shows a recent detection in **Protection history**. If you use another antivirus, check its own history too.
3. Send the detection name and loader version to your seller for investigation. Keep protection enabled while it is reviewed.

## Windows Firewall

**Message starts with:** `Windows Firewall is enabled.`

**Location:** Windows Security → **Firewall & network protection**.

<Frame caption="Microsoft reference screenshot: Firewall & network protection.">
  <img src="https://support.microsoft.com/en-us/windows/media/firewall-and-network-protection.png" alt="Windows Security Firewall and network protection screen with domain, private and public network profiles." />
</Frame>

**What to do:** Keep the firewall enabled. For a connection problem, first check whether other websites work, then follow [Connection and update errors](/troubleshooting/connection). On a managed PC, contact the network administrator.

[Microsoft's firewall guide](https://support.microsoft.com/en-us/windows/security/windows-security/firewall-and-network-protection-in-the-windows-security-app) explains the network profiles shown here.

## Device security

**Location:** Windows Security → **Device security → Core isolation details**.

<Frame caption="Microsoft reference screenshot: Device security. Select Core isolation details to inspect Memory integrity.">
  <img src="https://support.microsoft.com/en-us/windows/media/device-security.png" alt="Windows Security Device security screen showing the Core isolation section and its details link." />
</Frame>

<AccordionGroup>
  <Accordion title="Memory Integrity (HVCI) is running">
    **Meaning:** Windows is protecting kernel code with Memory integrity.

    **What to do:** Keep it enabled. Install Windows and manufacturer driver updates. If a driver is reported as incompatible, ask the publisher for a compatible replacement.
  </Accordion>
  <Accordion title="The vulnerable driver blocklist is configured on">
    **Meaning:** Windows reports that its vulnerable-driver blocklist is configured. This message alone does not identify which driver, if any, was blocked.

    **What to do:** Keep the blocklist enabled. If Windows names a blocked driver, send its name to your seller and request an updated, compatible driver. Do not install an older vulnerable driver to work around the block.
  </Accordion>
</AccordionGroup>

[Microsoft's Device security guide](https://support.microsoft.com/en-us/windows/security/windows-security/device-security-in-the-windows-security-app) describes Memory integrity and the driver blocklist.

## Valorant Vanguard is running

**Message starts with:** `Valorant Vanguard is running.`

**Meaning:** The loader reports that Riot Vanguard's driver is running. Closing a game window does not necessarily stop a background driver.

**What to do:** Close the loader and ask your seller to confirm whether the current build supports this configuration. Keep Windows and your applications updated; do not alter anti-cheat services or drivers to bypass the check.

## The message says the status could not be determined

That is a different result from a protection being enabled. See [Status-check failures](/common-errors/status-checks).
