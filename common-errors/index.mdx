## Start here

1. Note the exact message and your loader version.
2. Restart Windows if an update or installer is waiting for a restart.
3. Use the current approved loader from your seller.
4. If the same message returns, follow the matching guide above.

<Note>
A security feature being enabled is normal. A message asking you to disable protection does not, by itself, establish a fault in Windows. Keep protections enabled and ask your seller for a compatible build if the loader cannot continue.
</Note>

## Still stuck?

Send your seller the exact message, loader version and Windows version. To find the Windows version, open **Start**, type **winver**, and press **Enter**. Hide personal details before sharing an image of an error.

If you need an account or hardware reset, [contact a seller](/resets) so they can handle it through the bot.
